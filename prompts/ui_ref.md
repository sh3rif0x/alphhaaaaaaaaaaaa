
Create a premium, production-quality UI design showcase board.

I am attaching ONE reference image. It can be any kind of UI: a website, hero section, landing page, phone app, tablet app, dashboard, or a single screen.

Use the image as your SOURCE OF DATA and INSPIRATION, then design a NEW, COMPLETE UI from it. Do NOT copy the layout of the image.

==================================================
STEP 1: EXTRACT THE DATA FROM THE IMAGE
==================================================

Read the image and collect every piece of data it contains:
- brand name and logo
- business type and industry
- headlines, subheadlines, button text, menu items, labels
- services, products, features, statistics, reviews, prices
- color palette
- typography mood
- photography subject and style
- interface type (website, phone app, tablet app, dashboard, etc.)
- language of the text

==================================================
STEP 2: USE THE DATA, OR GENERATE IT
==================================================

RULE:
- If the data exists in the image, USE IT exactly (brand name, industry, headline, colors, language, etc.).
- If the data you need does NOT exist in the image, GENERATE it yourself, based on the brand, industry and mood of the image.

Examples:
- Brand name visible in the image: use that exact name. Not visible: invent one that fits the industry.
- The image shows a painting company: the new design is about that painting company, with painting services, a painting portfolio, painting reviews, and so on.
- The image shows only a hero section: generate the other sections (services, process, portfolio, stats, testimonials, pricing, contact, footer) for the same business.
- The image shows only one phone screen: generate additional screens for the same app.
- Text in the image is garbled or misspelled: rewrite it clearly and correctly.

Everything you add must feel like it belongs to ONE real brand in ONE industry.
Never switch to another industry or another color scheme.

==================================================
STEP 3: CREATE A NEW DESIGN
==================================================

Do NOT recreate the reference screenshot.
Design a fresh, polished, more complete UI using the extracted and generated data.
You may add new sections, new screens, new cards, new components, new text and new photos wherever they make the design stronger.
Keep the same interface type as the reference: a website stays a website, a phone app stays a phone app.

==================================================
STEP 4: LAYOUT, TWO-COLUMN EDITORIAL / MASONRY BOARD
==================================================

Arrange the new design as a TWO-COLUMN editorial / masonry composition:

LEFT COLUMN + RIGHT COLUMN, side by side, both clearly visible.

LEFT COLUMN: the main brand identity, hero or main screen, headline, main CTA, plus supporting blocks below.
RIGHT COLUMN: additional sections or screens, cards, features, stats, testimonials, pricing, contact and footer.

Rules:
- Each column is an independent vertical stack of separate rounded blocks.
- The two columns must not repeat the same content.
- Use different block heights so the rows do NOT line up (large, medium and small blocks, wide banners).
- Both columns belong to the same design system.
- Columns are about 50% width each with a refined gutter and never touch.
- Both columns end at about the same height.
- The two-column structure is obvious at first glance.

==================================================
CANVAS
==================================================

- 4:5 vertical ratio, preferred size 1080 × 1350 or 1152 × 1440
- The entire composition fits inside the image, nothing cropped
- Consistent outer margins
- No browser frame, no laptop frame, no floating objects outside the board
- Phone or tablet frames only if the reference is a phone or tablet app
- ONE coherent composition

==================================================
VISUAL QUALITY
==================================================

- Strong visual hierarchy, consistent spacing and corner radius, clean alignment
- Premium typography, clear primary and secondary buttons, refined icons
- Color system taken from the reference: one dominant color, one accent, neutral background, dark text
- Photorealistic, premium imagery matching the business
- All text sharp, readable and correctly spelled
- No lorem ipsum, no placeholder text, no repeated sentences
- No clutter, no random gradients, no excessive glassmorphism, no unnecessary 3D
