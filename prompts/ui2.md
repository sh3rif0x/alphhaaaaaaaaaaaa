==================================================

A strong primary visual flow containing the main brand introduction and several major content sections.

RIGHT COLUMN:
A secondary visual flow containing supporting sections, feature grids, product/service content, testimonials, conversion sections and footer content.

The two columns should feel like parts of the SAME WEBSITE, not two unrelated websites.

Use:
- Consistent spacing
- Consistent card radius
- Consistent typography
- Consistent grid system
- Strong visual hierarchy
- Clear alignment
- Repeating design language
- Carefully balanced whitespace

- Right: 50%

with refined gutters and spacing.
