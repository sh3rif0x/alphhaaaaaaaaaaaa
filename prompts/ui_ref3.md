==================================================
STEP 1: EXTRACT EVERYTHING FROM THE IMAGE
==================================================

Read the image and collect:
- brand name and logo
- business type and industry (what the company actually does or sells)
- headlines, subheadlines, button text, menu items, labels
- services, products, features, stats, reviews, prices
- color palette and how colors are distributed
- typography style, weights and hierarchy
- card style, corner radius, borders, shadows, icon style, button style
- photography subject and style
- interface type (website stays a website, phone app stays a phone app)

==================================================
STEP 2: USE THE DATA, OR GENERATE IT
==================================================

- If the data EXISTS in the image: use it (brand name, industry, headline meaning, colors).
- If the data does NOT exist: generate it yourself, based on the brand, industry and mood of the image.
- If the text in the image is garbled or misspelled: rewrite it clearly and correctly.
- If the image shows only one part (just a hero, or just one phone screen): generate the remaining sections or screens for the SAME business (services, process, portfolio, stats, testimonials, pricing, contact, footer, or extra app screens).

LANGUAGE RULE:
- The final design must be written in ENGLISH ONLY.
- If the text in the reference image is in English, keep it in English.
- If the text in the reference image is in ANY other language (Arabic, German, French, Spanish, etc.), translate its meaning into natural, professional English and use the English version everywhere in the new design.
- Keep the brand name as it is. If the brand name is in a non-Latin script, keep the original name and, where it fits, add a clean English/Latin version of it.
- Do NOT mix languages. Every headline, button, label, menu item, stat and review must be in English.
- Because the text is English, use left-to-right layout direction (LTR), even if the reference was right-to-left.

Everything must feel like ONE real brand in ONE industry.
Never switch industry, brand, or color scheme.
Example: a painting company must never become a fitness app.

==================================================
STEP 3: KEEP THE REFERENCE'S DESIGN LANGUAGE
==================================================

Follow the reference closely in:
- proportions and relative element sizes (logo, headlines, body text, buttons, images, cards, icons)
- alignment system (shared left/right edges, centered elements, text-to-image relationships)
- spacing rhythm (margins, gutters, card gaps, padding)
- hero composition and image shape/crop style
- typography hierarchy
- overall mood, premium feel and visual identity

The result must immediately feel like it belongs to the same design family as the reference, but it is a NEW and more complete design.

==================================================
STEP 4: LAYOUT, TWO-COLUMN EDITORIAL / MASONRY BOARD
==================================================

Arrange the design as a TWO-COLUMN masonry composition, both columns clearly visible side by side.

LEFT COLUMN: main brand identity, hero or main screen, headline, main CTA, then supporting blocks below.
RIGHT COLUMN: additional sections or screens, cards, features, stats, testimonials, pricing, contact/footer.

Rules:
- Each column is an independent vertical stack of separate rounded blocks.
- The two columns must NOT repeat the same content.
- Use different block heights so rows do NOT line up (large, medium, small blocks, wide banners).
- Both columns share the same design system.
- Columns are about 50% width each, with a refined gutter. They never touch.
- Both columns end at about the same height.
- Consistent corner radius, padding and alignment in all blocks.
- The two-column structure must be obvious at first glance.
