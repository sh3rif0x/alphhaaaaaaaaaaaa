# AI ARMY 2026 — Free-Tier Stack for a Web Development Company

> **Purpose:** A practical, zero-budget AI stack for building websites, creating marketing assets, producing content, generating video/voice, doing SEO, researching prospects, and running social media.
>
> **Last checked:** September 2026
>
> **Important:** “Free” means a currently usable free tier, free credits, open-source/self-hosted access, or a free plan. Limits, model names, watermarks, licensing, and regional availability change frequently. Always verify the provider’s current terms before using output for paid client work.

## How to use this file

Do **not** try to use every tool every day. Build a small core stack and keep the rest as backup weapons.

### Core philosophy

1. **One primary tool per job.**
2. **Two backups per important job.**
3. **Never depend on one AI provider.**
4. **Use AI for speed, but manually verify client-facing claims, code, facts, licenses, and brand assets.**
5. **For commercial work, check the current free-plan license before delivery.**

### Coding battle plan

**Use first:** Gemini CLI or your preferred free frontier model.

**Use Copilot Free for:** autocomplete and small edits. GitHub currently lists 2,000 completions/month on Copilot Free, plus limited chat/agent usage. citeturn1search0turn1search3

**Use Claude/ChatGPT for:** architecture, difficult bugs, explaining unfamiliar code, writing tests, and reviewing generated code.

**Use Cline/Aider for:** repository-level agent workflows when you have a suitable free/local model available.

### Coding prompt

```text
You are the senior engineer reviewing this project.
1. Understand the existing architecture before changing anything.
2. Do not rewrite working code unnecessarily.
3. Identify security, performance, accessibility and SEO risks.
4. Give the smallest safe patch first.
5. Explain files changed and why.
6. Provide tests or verification commands.
7. Never invent APIs or package behavior; say when uncertain.
```

# 15. ZERO-BUDGET DAILY WORKFLOW

## Morning — Research

1. Check Google Trends.
2. Search competitors.
3. Use Perplexity for source-backed research.
4. Ask ChatGPT/Gemini to turn research into content opportunities.

## Content production

1. ChatGPT/Claude → script/copy.
2. Gemini/Perplexity → research verification.
3. Ideogram/Leonardo → visual.
4. Kling/Hailuo/Pika → short video.
5. ElevenLabs → voiceover.
6. CapCut → final edit.
7. Canva → thumbnail/carousel.

## Sales

1. Find businesses with weak websites.
2. Research each prospect.
3. Use AI to identify observable website problems.
4. Create a 30–60 second personalized teardown.
5. Send a concise outreach message.
6. Track responses in a simple CRM/Sheet.

## Development

1. Plan with ChatGPT/Claude/Gemini.
2. Build with your IDE + Copilot/Cline.
3. Test manually.
4. Ask a second model to review the code.
5. Run lint/tests/security checks.
6. Deploy through your normal CI/CD workflow.

# 19. FREE-TIER RULES

### Green — usually safe to test

- Free plan that renews/refills
- Open-source software
- Local models with a suitable license
- Free analytics/search tools

### Yellow — verify before client delivery

- Free AI image/video output
- Voice cloning
- Stock/music generation
- AI-generated logos/brand assets
- Outputs with watermarks
- Tools that make content public by default

### Red — don't assume it is commercially usable

- Free trial that expires
- “Free to generate” but commercial rights are restricted
- Voices cloned without permission
- Music/assets with unclear licensing
- Client confidential information pasted into a service without checking its data policy
- Generated code shipped without security/testing review
